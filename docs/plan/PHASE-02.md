# Phase 2 — React + TypeScript + Vite

## 阶段目标

将原生 MVP 演进为组件化、类型更清晰、便于持续扩展的前端应用。

## 为什么学习

Phase 1 会暴露 DOM 操作重复、界面状态分散和页面复用困难等问题。React 用组件和声明式更新处理复杂界面，TypeScript 帮助发现数据结构和接口使用错误，Vite 提供现代前端开发基础。

## 核心知识

- React 组件、属性、状态和生命周期思维
- 事件、表单和条件渲染
- 组件组合与数据流
- TypeScript 类型、接口和泛型基础
- Vite 与前端构建流程
- 模块化、依赖和开发工具

## 核心功能

- 重建 Dashboard、记录、任务和项目界面
- 复用列表、表单、卡片等界面单元
- 保持 MVP 的本地数据能力
- 改善状态变化和页面之间的数据同步

## 技术范围

引入 React、TypeScript 和 Vite，仍以浏览器本地数据为主。暂不引入后端、数据库、复杂状态管理或过度抽象。

## 阶段产出

一个结构清晰、组件化、具有基本类型约束的 StudyOS 前端版本。

## 验收方向

### 功能验收

原有 MVP 能力在新前端中保持可用。

### 技术验收

组件、状态、属性和类型边界使用合理。

### 知识验收

能解释声明式 UI、组件职责和 TypeScript 类型检查的价值。

### 工程验收

模块划分可理解，构建和开发流程稳定，没有无理由的复杂抽象。

## 与下一阶段的关系

前端需要从浏览器本地数据获取更可靠、可共享的数据服务，因此自然需要理解 HTTP、API 和后端基础。
