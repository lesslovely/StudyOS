# Phase 7 — LLM / AI 能力

## 阶段目标

在真实学习场景中引入大语言模型，构建可解释、可控制的 AI 学习辅助能力。

## 为什么学习

当学习记录和任务形成连续数据后，自动总结、知识提取和复习辅助具有真实价值。此时引入 AI 是解决问题，而不是展示技术。

## 核心知识

- LLM API 的基本交互
- Prompt 设计与上下文组织
- 结构化输出与结果校验
- 重试、超时、成本和速率限制
- 隐私、安全与 AI 输出不确定性
- AI 功能的效果评估

## 核心功能

- 学习记录总结
- 知识点提取
- 复习问题生成
- 基于历史内容的学习辅助
- 基础学习状态分析

## 技术范围

使用 LLM API 和应用层 AI 能力。具体模型、供应商和调用框架不提前锁定。暂不引入 RAG 或 Agent，先理解单次 AI 能力的边界。

## 阶段产出

一个能够基于用户主动提供内容完成有限辅助任务、并对结果进行基本控制和反馈的 AI 功能层。

## 验收方向

### 功能验收

AI 能完成明确的总结、提取或生成任务，并能处理失败情况。

### 技术验收

上下文、输出校验、错误处理、成本和权限边界合理。

### 知识验收

能解释模型输入输出、Prompt、幻觉和结构化结果的基本问题。

### 工程验收

AI 功能与核心业务解耦，关键数据和调用行为可追踪。

## 与下一阶段的关系

单次输入无法充分利用长期积累的个人资料。若用户希望基于自己的知识回答问题，就需要检索个人内容并把相关内容提供给模型，因此进入 RAG。
