# Phase 1 — HTML + CSS + JavaScript 前端 MVP

## 阶段目标

使用浏览器原生能力完成 StudyOS 的第一个可运行版本，建立从页面结构、样式、DOM 操作到本地数据保存的完整基础。

## 为什么学习

这是距离当前已掌握知识最近的真实项目阶段。先用简单技术验证需求，能够理解应用本质，避免在尚未理解问题前引入框架。

## 核心知识

- 语义化 HTML 与表单
- CSS 布局、响应式和界面组织
- JavaScript 事件与 DOM
- 数据与 UI 的同步
- 对象、数组和基础数据建模
- localStorage 与 JSON
- 基础调试、测试和错误排查

## 核心功能

- Dashboard
- 学习记录的创建、查看、编辑和删除
- 学习任务的创建、查看、完成和删除
- 项目的创建、查看、编辑、删除和进度展示
- 本地数据保存与刷新后恢复
- Dashboard 与实际数据联动

## 技术范围

使用 HTML、CSS、JavaScript、Browser DOM API 和 localStorage。暂不使用 React、TypeScript、Node.js、npm、后���、数据库或第三方 UI 框架。

## 阶段产出

一个可在浏览器中运行、能够管理基础学习数据并在刷新后保留数据的原生前端 MVP。

## 验收方向

### 功能验收

核心记录、任务、项目流程可用，Dashboard 展示真实数据。

### 技术验收

能正确使用语义化结构、事件、DOM、数据对象、数组和 localStorage。

### 知识验收

能解释数据与 UI 的关系、JSON 转换和浏览器本地存储限制。

### 工程验收

结构清晰、无明显重复、具备基本响应式和手动测试记录。

## 与下一阶段的关系

当页面和交互增加后，直接操作 DOM 会使组件复用、状态管理和维护变得困难；此时需要学习 React，并用 TypeScript 增强大型前端的可理解性。
