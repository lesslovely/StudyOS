# Phase 9 — AI Agent + Tool Calling

## 阶段目标

让 AI 在明确权限和规则下调用 StudyOS 能力，完成多步骤学习辅助工作流。

## 为什么学习

单次问答和 RAG 主要提供信息。更复杂的学习辅助需要查询记录、分析状态、制定计划并执行有限操作，这要求模型与工具协作。

## 核心知识

- Tool Calling
- 工具定义与参数校验
- Agent 工作流与状态
- 任务分解和结果验证
- 权限、确认机制和副作用控制
- 可观测性、失败恢复和人工介入

## 核心功能

- 查询学习记录、任务和项目
- 分析学习状态
- 制定学习计划
- 在用户确认后创建或更新学习任务
- 组合知识检索与业务工具

## 技术范围

使用受控工具调用和工作流。具体 Agent 框架、模型和编排方案不提前决定。禁止让模型获得无限制的数据库或系统权限。

## 阶段产出

一个权限明确、操作可解释、必要时需要用户确认的 AI 学习工作流能力。

## 验收方向

### 功能验收

Agent 能正确选择工具、完成查询并对写操作进行适当确认。

### 技术验收

参数、权限、状态、失败和副作用处理清晰。

### 知识验收

能解释模型决策、工具调用、工作流和 Agent 与普通问答的区别。

### 工程验收

关键操作可审计，可回滚或恢复，系统不会盲目信任模型输出。

## 与下一阶段的关系

功能和系统边界逐渐复杂，必须通过测试、清晰的 Git 历史和工程流程控制回归风险，因此进入测��与工程化阶段。
